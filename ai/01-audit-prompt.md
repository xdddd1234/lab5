# Запит на AI-аудит UML Component Diagram

## Контекст

Лабораторна робота №5.

Система: бібліотечна система.

Процес: UC-03 «Видача книги».

Нотація: UML Component Diagram (PlantUML).

Файли для перевірки:

- `spec.md`
- `diagrams/library-components.puml`
- `diagrams/library-components.svg`

## Завдання для AI

Проаналізуй компонентну архітектуру бібліотечної системи.

Перевір такі питання:

1. Чи всі основні компоненти системи представлені на діаграмі?
2. Чи правильно визначена межа Library System?
3. Чи правильно розподілено відповідальність між Library UI, Library API, сервісами та репозиторіями?
4. Чи для кожної залежності визначено required-інтерфейс?
5. Чи кожен required-інтерфейс має відповідний provided-інтерфейс?
6. Чи немає зайвих або циклічних залежностей?
7. Чи правильно показано доступ до Library Database?
8. Чи узгоджуються компоненти з моделлю даних лабораторної №1?
9. Чи підтримує архітектура UC-03 та сценарії лабораторної №2?
10. Чи відповідає архітектура учасникам sequence-діаграм лабораторної №3?
11. Чи підтримує архітектура процес Activity Diagram лабораторної №4?
12. Чи обґрунтована відсутність зовнішніх інтеграцій?
13. Які три найважливіші розбіжності потрібно виправити?

## Очікуваний результат

Для кожної проблеми вкажи:

- Назву проблеми.
- Де саме вона виникає.
- Чому це проблема.
- Запропонований спосіб виправлення.
- Зв'язок із попередніми лабораторними.

Наприкінці сформуй TOP-3 найважливіших розбіжностей.

Не додавай нових бізнес-вимог без підтвердження. Якщо інформації недостатньо, постав уточнювальні питання.
